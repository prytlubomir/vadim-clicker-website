# Vadim's Clicker Website

This is a repository for the [Vadim's Clicker](https://github.com/prytlubomir/vadim-clicker) project website by [Pryt Liubomyr](pryt.space).

You can visit it at (https://vadimsclicker.pryt.space/)

## Notes

- `.js` files are treated as `ECMAScript Modules`. <br/>
  If you want your script to be treated as `CommonJS`, please use `.cjs` extension.

## Testing

To run tests, execute `npm test`.

You'll see short logs in your terminal window.

See generated `test-report.txt` for the detailed test report.
